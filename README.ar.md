# مكتبة أدوات بلغة C++

مجموعة تعليمية من الدوال المساعدة القابلة لإعادة الاستخدام بلغة C++. يجمع المشروع توليد البيانات العشوائية وعمليات المصفوفات والتبديل وتحويل النصوص البسيط وأدوات التاريخ ضمن ترويسات مبنية على الأصناف.

## وظائف المكتبة

- تهيئة مولّد الأرقام شبه العشوائية وتوليد الأرقام
- توليد الأحرف الصغيرة والكبيرة والأرقام والأحرف المختلطة والكلمات والمفاتيح المنسقة
- تبديل الأعداد الصحيحة والعشرية والنصوص وكائنات `clsDate`
- طباعة المصفوفات ثابتة الحجم وخلطها وتعبئتها
- إنشاء نصوص مسافة بادئة باستخدام Tab
- تطبيق تحويل بسيط بإزاحة الأحرف وعكسه
- استخدام مساعد `clsDate` المرفق لعمليات التاريخ

## التقنيات والمفاهيم

- C++
- الدوال الساكنة وزيادة تحميل الدوال
- Microsoft Visual C++ وVisual Studio
- النصوص والمتجهات والتدفقات ودوال الوقت من المكتبة القياسية

## بنية المشروع

```text
Utility_Library/
├── Utility Library.vcxproj
├── Utility Library.cpp  # نقطة دخول بسيطة لبرنامج Console
├── clsUtil.h            # الدوال المساعدة العامة
└── clsDate.h            # صنف التاريخ المستخدم في الأدوات
```

## البناء والتشغيل

المشروع مضبوط على أداة Visual Studio 2019 المسماة `v142` ولا يحتوي على ملف Solution.

1. افتح `Utility Library.vcxproj` في Visual Studio.
2. ثبّت v142 أو أعد استهداف المشروع إلى أداة C++ مثبتة.
3. ابنِ إعداد `Release | x64`.

عبر Visual Studio Developer PowerShell:

```powershell
msbuild "Utility Library.vcxproj" /p:Configuration=Release /p:Platform=x64
```

## مثال

```cpp
#include "clsUtil.h"

int main()
{
    clsUtil::Srand();
    int number = clsUtil::RandomNumber(1, 100);
    std::string key = clsUtil::GenerateKey(clsUtil::CapitalLetter);
}
```

## التحقق من البناء

نجح بناء المشروع بعد استخدام أداة v145 المثبتة مؤقتًا بدل v142 المضبوطة. يعرض المترجم تحذيرات تخص رموزًا إضافية بعد بعض أوامر `#include`، وتحويلات قد تفقد جزءًا من القيمة، وأسلوب تعريف التعداد.

## ملاحظة أمنية

تصلح `rand()` والمفاتيح المولدة ودوال إزاحة الأحرف للتعلم وبيانات الاختبار غير الحساسة فقط. هذه الأدوات ليست آمنة تشفيريًا، ويجب عدم استخدامها لكلمات المرور أو الرموز السرية أو التشفير أو حماية معلومات حقيقية.

## النطاق الحالي

- تستقبل أدوات المصفوفات تواقيع مصفوفات C ثابتة الحجم، ويجب على المستدعي تمرير طول صحيح.
- يمكن تحسين دقة بعض الأسماء وأنواع القيم المعادة.
- يجعل صنف التاريخ المرفق نطاق المستودع أوسع من مكتبة أدوات عامة مركزة.
- لا يفعل البرنامج التنفيذي سوى تهيئة مولّد الأرقام العشوائية، وليس مجموعة أمثلة متكاملة.

## تحسينات مقترحة

- استبدال `rand()` بمكتبة `<random>` والفصل بين توليد بيانات الاختبار وأدوات الأمان
- استخدام القوالب أو `std::span` أو الحاويات بدل تواقيع المصفوفات الثابتة
- معالجة تحذيرات المترجم وإضافة التحقق من المدخلات
- نقل وظائف التاريخ إلى اعتماد مستقل على Date Library
- إضافة اختبارات آلية وأمثلة لكل دالة عامة
